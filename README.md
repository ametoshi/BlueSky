# ブルースカイ

Bluesky アカウントで端末をまたいでメモを同期できるシンプルな Web アプリです。

## できること

- **メインページ**でメモの作成・編集
- メモはまずこの端末（ブラウザ）に保存
- **同じ Bluesky アカウント**で別デバイスにログインし、「今すぐ同期」で共有

## 使い方

1. 依存関係を入れる

```bash
npm install
```

2. 開発サーバーを起動

```bash
npm run dev
```

3. Bluesky の [アプリパスワード](https://bsky.app/settings/app-passwords) を作成し、アプリからログインして同期する

## ビルド

```bash
npm run build
```

## 注意

- 通常のアカウントパスワードではなく、**アプリパスワード**を使ってください
- メモはカスタムレコードとしてあなたの PDS に保存されます（公開タイムラインには投稿されません）
